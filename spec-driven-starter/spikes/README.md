# spikes/: 🎸 vùng vibe coding

Muốn thử nhanh một ý tưởng, một thư viện, một giao diện? Làm ở đây, thoải mái, **không cần spec**.

Luật duy nhất: **không copy thẳng từ `spikes/` vào code chính.**

Ý tưởng đáng giữ thì nói với agent:
> "Mình đã vibe được bản demo trong spikes/<tên>. Chuyển nó thành spec."

Agent sẽ liệt kê hành vi của prototype, đánh dấu chỗ nghi là bug bằng `[NEEDS CLARIFICATION]`, rồi đưa vào `/speckit-specify` → clarify → plan → tasks → implement **lại cho đúng**.

> Vibe để học nhanh. Spec để xây chắc.
